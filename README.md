### Phase 2: React Fundamentals (Oct 22 – Nov 4)
- **Week 8:** React basics (components, props, state)
- **Week 9:** React intermediate (forms, lifecycle, hooks)

### Phase 3: Next.js + Real Project (Nov 5 – Nov 25)
- **Week 10:** Next.js basics
- **Week 11-12:** Full-stack project

### Phase 4: Job Prep (Nov 26 – Nov 30)
- Portfolio polish, resume, interview prep
